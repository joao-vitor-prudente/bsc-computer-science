# Equivalences

- $\lnot(p \land q) \equiv \lnot p \lor \lnot q$
- $\lnot(p \lor q) \equiv \lnot p \land \lnot q$
- $p \rightarrow q \equiv \lnot p \lor q$

To test that understanding, let's try a quick practice problem. If $P$ is true and $Q$ is false, what is the truth value of the following formula: $(P \text{ AND } Q) \text{ OR } (\text{NOT } P)$?
